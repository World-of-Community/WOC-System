## Run it
(Set up Discord bot at https://discord.com/developers/home)
1. npm install
2. cp .env.example .env
3. Fill in values
4. npm start

## What I did here
### 1. Seasonpass
What it is: A SeasonPass. You get XP by writing, and with that XP you can buy a new level of the Pass. There is Premium which gives you access to the Premium Stages, and you can donate it to other people with `/seasonpass verschenken`. It is also on the Leaderboard with `/leaderboard kategorie:🎟 - SeasonPass-Stufe`!
### 2. Fix Texts
There were many grammar issues and wrong spelling, so I repaired it. Didn't take that long, but I wanted to mention it.
