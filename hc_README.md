# Discord bot for WOC

This is a discord bot for the WOC discord server: https://discord.gg/GqnEzjVdH2
It is the Service bot, not the Support bot!

## Features

- Management of Admin Features
- Funny stuff
- Events
- Giveaways
- Leaderboard
- Birthdays
- Even more

## Run it

1. npm install
2. cp .env.example .env
3. Enter values
4. npm start
